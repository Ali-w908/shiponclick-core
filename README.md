# ShipOnClick Core

The open-source, stripped-down version of the Next.js SaaS Starter Kit.

## Features Included
- **Auth**: NextAuth.js with Credentials, Google, and GitHub providers.
- **Billing**: LemonSqueezy integration for subscription management.
- **CLI Setup**: The "On Click" promise - run `npm run setup` to easily configure your environment.
- **Dashboard**: A fully responsive dashboard with team management capabilities.
- **Database**: Prisma ORM with PostgreSQL.

## Getting Started

1. Clone the repository and install dependencies:
   ```bash
   git clone https://github.com/Ali-w908/shiponclick-core.git
   cd shiponclick-core
   npm install
   ```

2. Run the interactive setup:
   ```bash
   npm run setup
   ```
   *This will generate your .env file and configure your initial secrets.*

3. Start the development server:
   ```bash
   npm run dev
   ```
